# 環遊世界 365 天

[開啟網站](https://xhw0122-web.github.io/https-island-days-tw-1113.workspace-926599.chatgpt.site-/)

以台灣為起終點，透過世界地圖和 12 個月行程安排一年旅行。網站可設定出發日期與全年預算，也能離線閱讀行程和查看路線。

站點位於 `1113/island-days/dist/`。推送至 `main` 時，GitHub Actions 會執行測試並發布到 GitHub Pages。

```sh
cd 1113/island-days
npm run dev
npm test
```

參閱[專案說明](1113/island-days/README.md)瞭解行程資料、預算與底圖來源。
