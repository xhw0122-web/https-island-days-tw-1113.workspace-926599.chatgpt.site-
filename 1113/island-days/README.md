# 島日子｜真實活動探索

目前人工查核收錄8筆真實活動，最後查核2026/11/13。每筆活動皆附官方／主辦／指定報名來源，並非即時同步服務。時間、價格、剩餘名額與異動應回官方確認。照片為Unsplash主題情境示意，非活動現場及官方海報。

`dist/activities.js` 保存活動、來源連結與查核備註；費用未確認使用null，不納入免費或付費篩選。日期依Asia/Taipei計算，展覽週一休館納入篩選。舊模擬收藏與真實資料分開，避免錯誤對應。

本機預覽：node serve.mjs，開啟http://localhost:4173。

地圖使用Leaflet及OpenStreetMap，座標為場館近似位置；無核實座標活動僅列清單，導航依地址／場館名稱。正式營運前需建立授權確認、固定更新與異動覆核流程。
