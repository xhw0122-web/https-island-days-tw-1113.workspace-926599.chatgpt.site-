# 島日子｜真實活動探索

目前收錄15筆真實活動與22筆常設景點，涵蓋全台22縣市，最後查核2026/11/13。每筆活動皆附官方／主辦／指定報名來源，並非即時同步服務。時間、價格、剩餘名額與異動應回官方確認。照片為Unsplash主題情境示意，非活動現場及官方海報。

`dist/activities.js` 保存活動、來源連結與查核備註；費用未確認使用null，不納入免費或付費篩選。日期依Asia/Taipei計算，展覽週一休館納入篩選。舊模擬收藏與真實資料分開，避免錯誤對應。

本機預覽：node serve.mjs，開啟http://localhost:4173。

地圖使用Leaflet及OpenStreetMap，座標為場館近似位置；無核實座標活動僅列清單，導航依地址／場館名稱。正式營運前需建立授權確認、固定更新與異動覆核流程。


新增資料取自交通部觀光署2026/11/13發布的[景點開放資料](https://data.gov.tw/dataset/7777)與[活動開放資料](https://data.gov.tw/dataset/7778)，依政府資料開放授權條款第1版使用；各筆保存來源ID、來源更新時間與官方詳細連結，描述為本站摘要。照片仍是主題情境示意。常設景點的日期為null，分類為spot，不宣稱全天或全年無休；請依官方開放時間與臨時管制。未知費用不列入免費或付費篩選。

蓬萊溪官方資料標示部分區域開放，頁面已保留提醒；後浦草地野餐音樂節的原始結構化起始時間與活動內文有差異，收錄日期採內文11月13日至15日並註明差異。藝術節等多場次活動僅顯示整體期間，不代表每天有節目。
